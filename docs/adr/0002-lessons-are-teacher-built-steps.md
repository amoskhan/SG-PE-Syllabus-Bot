# A lesson is an ordered list of steps the teacher builds

A lesson is not one fixed classroom flow, and not a pick from a few lesson formats. The teacher builds it from Teach, Practise and Assess steps in any order, with repeats allowed, and each Assess step chooses its own assessment method (AI analysis, peer assessment, or the teacher alone). Teachers plan lessons in very different ways: some lessons use AI, some use only a peer checklist so the teacher can grade afterwards, and some open with videos or pictures of the cues. A fixed flow or a short list of formats couldn't cover all of them.

## Consequences

- Each step names its own skill, and the lesson has one main skill that decides which student records its work is filed under.
- Pairs, check-in and the class QR are part of every lesson where pupils use devices, whatever its steps.
